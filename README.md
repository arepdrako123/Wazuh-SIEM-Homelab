# 🛡️ Wazuh SIEM Homelab

**Security Operations Center (SOC) | SIEM Deployment | Endpoint Monitoring | Threat Detection | Detection Engineering**

## 📌 Project Overview

The **Wazuh SIEM Homelab** is a hands-on cybersecurity project designed to simulate a Security Operations Center (SOC) environment using open-source security monitoring technologies.

The project focuses on deploying and configuring a centralized Security Information and Event Management (SIEM) platform to collect, analyze, and investigate security events generated by a Windows 11 endpoint.

The environment consists of a Wazuh SIEM server hosted on Ubuntu Linux within VMware Workstation, integrated with a Windows 11 host through the Wazuh Agent.

Through controlled security experiments, this project demonstrates practical experience in endpoint monitoring, file integrity monitoring, Windows authentication log analysis, and custom detection rule development.

The primary objective is to strengthen practical Blue Team skills by understanding how security events are collected, correlated, and transformed into actionable security alerts.

## 🚀 Project Implementation

### Phase 1 — VMware and Wazuh SIEM Deployment

Deployed an Ubuntu virtual machine using VMware Workstation and installed the Wazuh SIEM platform.

**Key Activities:**
- Configured Ubuntu Linux.
- Installed Wazuh Manager, Indexer, Dashboard and Filebeat.
- Verified SIEM service availability.
- Established network connectivity.

### Phase 2 — Windows Endpoint Integration

Installed and configured the Wazuh Agent on a Windows 11 endpoint.

**Key Activities:**
- Installed the Windows Wazuh Agent.
- Configured communication with Wazuh Manager.
- Verified agent registration and connectivity.
- Confirmed endpoint visibility through Wazuh Dashboard.

**Result:** Windows endpoint successfully connected to Wazuh SIEM.

### Phase 3 — File Integrity Monitoring

Implemented File Integrity Monitoring to detect unauthorized or unexpected file system changes.

**Security Tests:**
- File creation detection.
- File modification detection.
- File deletion detection.

**Result:** Wazuh successfully detected and recorded file integrity events in the monitored directory.

### Phase 4 — Windows Failed Login Detection

Configured Windows security auditing and investigated failed authentication attempts.

**Key Activities:**
- Enabled Windows login auditing.
- Generated a controlled failed login event.
- Identified Windows Event ID `4625`.
- Investigated the corresponding alert in Wazuh Threat Hunting.
- Verified Wazuh Rule ID `60122`.

**Result:** Windows authentication failure successfully detected with a Level 5 security alert.

### Phase 5 — Custom Detection Rules and Event Correlation

Developed custom Wazuh rules to detect simulated authentication failures and correlate repeated events.

**Custom Rules:**

| Rule ID | Detection | Severity |
|---|---|---|
| 100101 | Simulated Failed Login | Level 5 |
| 100102 | Repeated Failed Login Correlation | Level 10 |

**Testing Method:**
- Created custom XML detection rules.
- Validated rule configuration.
- Used Wazuh Logtest with simulated JSON events.
- Tested correlation of five matching events within a 120-second timeframe.
- Verified successful Level 10 alert generation.

**Result:** Custom detection and event correlation successfully validated in Wazuh Logtest.

*Note: These results demonstrate simulated JSON log detection. The separate Windows EventChannel correlation rule requires additional live-event validation.*
